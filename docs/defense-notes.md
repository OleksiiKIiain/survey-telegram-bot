# Короткий опис для захисту

Система має чітке розділення відповідальностей:

1. PostgreSQL зберігає адміністраторів, Telegram-респондентів, опитування, питання, варіанти, проходження, відповіді та audit logs.
2. FastAPI backend реалізує бізнес-логіку, авторизацію, API, аналітику та експорт.
3. Telegram bot використовує backend API для проходження опитувань.
4. React admin panel використовує той самий backend API для керування опитуваннями й перегляду статистики.

Демонстраційний сценарій:

1. Увійти в admin panel.
2. Показати seeded surveys і створити нове опитування.
3. Активувати опитування.
4. Пройти його через Telegram.
5. Показати збережені відповіді, dashboard, analytics і export.
