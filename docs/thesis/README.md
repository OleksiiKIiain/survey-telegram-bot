# Матеріали магістерської роботи

Текст є дослідженням реального Survey Bot, а не механічним об'єднанням звітів. Вихідні файли 01-05 містять анотації, вступ, три розділи та висновки. sources.json містить перевірені джерела; нумерація посилань формується за першою появою [@key]. Додатки генеруються з ORM-моделей, OpenAPI, протоколів і скриншотів.

## Збирання

На Windows із Times New Roman та Consolas потрібні Python-пакети python-docx, reportlab, pypdf, Pillow, lxml, pypdfium2. У середовищі Codex використано вбудований Python. Скрипт не використовує встановлений користувачем LibreOffice.

```powershell
python scripts/build_thesis.py
python scripts/qa_thesis.py
python scripts/check_artifacts.py
python -m unittest discover -s scripts -p test_artifact_checks.py -v
```

Результати: output/thesis/survey_bot_thesis.docx, survey_bot_thesis.pdf, technical_report.docx/pdf, compliance_report.docx/pdf. Цей каталог не комітиться. PDF генерується ReportLab із тих самих структурованих джерел, але не є перевіреною конвертацією DOCX. Word TOC створено як поле, фактичне оновлення потребує сумісного редактора.

artifact_checks.json містить структурні перевірки A4, полів, основного стилю DOCX, полів TOC/PAGE, порядку цитувань, сторінок заголовків PDF і наявності зображень. delivery_manifest.json фіксує розміри та SHA-256 фінальних файлів. Ці перевірки не замінюють візуальний рендеринг DOCX або перевірку академічної доброчесності. Негативні контрольні тести підтверджують виявлення неправильних полів, шрифту та порядку посилань.

## Докази й обмеження

- http_audit.json: 25 реальних HTTP-перевірок, зовнішній переклад 503 та короткий запуск 80 запитів.
- evidence/ui_audit.json: реальний браузер на ізольованій БД; скриншоти не містять основних реальних респондентів.
- backend/tests: інтеграція з реальною PostgreSQL, не mock.
- bot/tests: unit-тести обробників з AsyncMock, не Telegram E2E.
- materials-status.md: недоступні матеріали й офіційні реквізити.
- compliance-report.md: невиконані вимоги не позначаються виконаними.

Підключений Google Docs не змінювався. Відповідність додатку Е, офіційні реквізити, університетська перевірка унікальності та повна візуальна перевірка DOCX не підтверджені. До зняття цих обмежень матеріали не можна оголошувати остаточно готовими до подання.
