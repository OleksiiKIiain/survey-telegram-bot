# Відтворення перевірок із чистого репозиторію

Потрібні Git із повною історією, PowerShell 5.1 або новіший, Docker Desktop у режимі Linux containers і Docker Compose з командою `up --wait`. Вільний локальний порт: 8019. Початкове завантаження образів і залежностей потребує інтернету. Робочі `.env`, Telegram-токен і база `survey_bot` не використовуються.

Із кореня повного клону виконайте:

```powershell
powershell -NoProfile -File scripts/reproduce_audit.ps1
```

Скрипт сам готує `legacy-survey-schema.py` без змін через `git show 7929c0c:backend/app/schemas/survey.py`, створює папку доказів, піднімає окремий Compose-проєкт `survey-audit-evidence`, застосовує міграції й seed. У цьому проєкті є власна мережа та власний том. База має назву `survey_audit_reproduce`, службовий токен є нечинним тестовим рядком; polling бота не запускається.

Тестовій мережі явно призначено `10.213.88.0/24`, щоб не залежати від вичерпаного автоматичного пулу Docker на хості. Якщо ця підмережа вже використовується, перед запуском задайте `$env:AUDIT_SUBNET='ІНША_ВІЛЬНА_ПІДМЕРЕЖА/24'`. Чужі мережі видаляти не потрібно.

Перевірки виконуються в такому порядку:

1. `python -m tests.supervisor_audit`: 16 PostgreSQL-тестів і 3 тести сумісності Google-провайдера з підміною мережі; додатково експеримент зі старою схемою та контроль цілісності.
2. `python -m unittest tests.test_translation -v`: 7 модульних тестів MyMemory, UTF-8, порожніх рядків, квоти та тайм-ауту. Мережа підміняється.
3. `python -m tests.http_audit`: 25 HTTP-тверджень; зовнішній переклад перевіряється окремим запитом, його статус не підміняє ці 25 результатів.
4. `python -m tests.repeat_load`: 5 прогрівальних запитів і 3 серії по 80 запитів, 8 потоків.
5. `pg_dump` у custom-форматі; створення нової порожньої `survey_audit_restore_ЧАС`; `pg_restore --exit-on-error`; порівняння рядків через `tests.verify_restore` із явно переданими іменами БД.
6. Окремий одноразовий контейнер бота: 18 unit-тестів, без реальних повідомлень.
7. Окремий одноразовий frontend-контейнер: `npm run build`.

Журнал усіх команд і результати: `output/audit-reproduction/commands.log`. Машиночитані протоколи: `supervisor-audit.json`, `repeat-load.json`, `backup-restore.json` у цій самій папці; HTTP-протокол друкується в журнал. Значення ID та часів можуть відрізнятися: перевіряти слід інваріанти, а не конкретні первинні ключі попереднього запуску.

На виході тестові сервіси зупиняються через `down` без `-v`. Для огляду API після тестів використайте `-KeepRunning`, відкрийте `http://localhost:8019/docs`. Зупинка лише тестового середовища:

```powershell
docker compose -p survey-audit-evidence -f docker-compose.audit.yml down
```

Операції не видаляють робочих даних. Повторний запуск використовує той самий тестовий том, але створює нову БД відновлення. Якщо порт 8019 зайнятий, слід звільнити його або змінити тільки port mapping тестового Compose-файлу.

## Реальний переклад

Типовий провайдер — MyMemory (`TRANSLATION_PROVIDER=mymemory`). Альтернативний `google` збережено для сумісності; доступність залежить від зовнішніх квот. Текст анкети надсилається вибраному сторонньому сервісу лише після адміністративної дії. Для MyMemory запити розбиваються на сегменти не більше 500 UTF-8 байтів, із тайм-аутами підключення та читання. Помилки, квоти й порожня відповідь дають 503 без фіктивного перекладу. Сервіс має власні ліміти; це не SLA. Вільні коментарі респондентів автоматично не перекладаються.

Офіційний опис API: https://mymemory.translated.net/doc/spec.php .
